# AxiomPitch

Веб-помощник для презентаций, питчей и выступлений с управлением жестами.

В верхней части экрана — чёрная чёлка с живым синим силуэтом головы, плеч и рук
выступающего. При срабатывании жеста появляется короткая ненавязчивая анимация.
Неточное движение сопровождается конкретной подсказкой.

## Текущий статус

Создана основа фронтенда: React + TypeScript + Vite, стили, чёрная чёлка
в состоянии «Камера не подключена» и демонстрационная презентация с ручным
переключением слайдов. Production-сборка проверена.

Камера, живой силуэт, распознавание жестов, загрузка PDF, статистика и бек
**ещё не реализованы**. Установленные библиотеки не означают готовность этих функций.

## Запуск

Требуется Node.js 22.12+ (проверено на Node.js 22.23.1) и npm.

```bash
npm ci
npm run dev
```

Адрес локального приложения выводится в терминале.

```bash
npm run build
npm run preview
```

Команда build включает проверку TypeScript. Дополнительно: `npm run lint`.

## Стек

| Задача | Технология |
| --- | --- |
| Интерфейс | React + TypeScript |
| Запуск и сборка | Vite |
| Стили | Tailwind CSS + CSS |
| Отслеживание тела/рук и сегментация | MediaPipe Tasks Vision |
| Синий силуэт | Canvas 2D |
| Мини-анимации | Motion |
| PDF-презентации | PDF.js |
| Иконки | Lucide React |

Серверную часть реализует отдельно разработчик бека.

## План обязательного MVP

- [ ] Камера и живой синий силуэт в чёлке.
- [ ] Три команды: вправо, влево, удержание ладони.
- [ ] Защита от случайных переключений во время жестикуляции.
- [ ] Режим «ошибка» с конкретными подсказками.
- [ ] Загрузка PDF-презентации.
- [ ] Сценарий от подготовки до итогов выступления.
- [ ] Отдельный экран аудитории.

Архитектура и разделение работы: [docs/architecture.md](docs/architecture.md).
