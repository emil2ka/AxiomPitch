# Перенос AxiomPitch-design на актуальный AxiomPitch

Основа — GitHub main на коммите `7b71f55`. Перенос выполнен в ветке
`codex/design-integration`. Исходная папка AxiomPitch-design не изменялась.

## Готовые экраны

| Экран | Что перенесено |
| --- | --- |
| `/` | Лендинг, прокрутка истории, интерактивное демо, девять анимаций помощника |
| `/register` | Существующая демо-форма без создания аккаунта |
| `/learn` | Отдельное обучение, примеры, проверка команд, мини-репетиция |
| `/studio` | Компоновка студии, миниатюры, заметки, камера, таймер, результаты и история |
| `/companion` | Просмотр 3D-персонажа и примеров движений |
| `?audience=1` | Прежняя синхронизация окна аудитории, общий компонент слайда |
| `?overlay=1` и `/overlay` | Внешний вид зеркала из design через прежний Electron-мост |

## Сохранённые функции свежей версии

- Сервер на `127.0.0.1:8787`, SQLite, HTTP API презентаций, заметок и результатов.
- WebSocket-связь студии и Electron, выбор дисплея через существующий API.
- Адаптеры Keynote, PowerPoint, Chrome/Google Slides и выбранного приложения.
- Маршрутизация кнопок, клавиатуры и распознанных жестов во внешнюю цель.
- Блокировка без отправки `toggle` в презентацию, обработка отказа приложения.
- Оценочный номер со знаком `≈`, запрет произвольного перехода по миниатюрам
  при подключённой внешней цели.
- Загрузка копии PDF на локальный сервер, сохранение заметок с задержкой,
  результатов и прежняя локальная история. Без моста колода продолжает работать.

Серверные маршруты, БД и адаптеры не заменялись дизайн-копией. Единственное
расширение протокола кадров — необязательный `handScores`: уверенность определения
левой/правой руки для новой модели. Сервер валидирует значения и по-прежнему
пересылает только координаты и метаданные отслеживания, без видео.

## Решения, которые стоит обсудить

1. **Правила жестов взяты из design.** Обучение и студия используют один движок:
   достаточно ладони без плеч, после свайпа руку можно оставить в кадре,
   после удержания нужен сброс. Это функциональная доработка пользователя,
   которая соответствует его готовому обучению. Подключение внешних целей
   друга сохранено. Если вернуть прежние правила по плечам, нужно одновременно
   менять обучение и тексты подсказок.
2. **Оболочка чёлки — Electron друга.** Внешний вид 220×80 взят из design.
   Крестик скрывает чёлку до нового выступления, включение в настройках сохраняется.
   Показ автоматический во время сеанса; завершение, закрытие вкладки или потеря
   heartbeat более 5 секунд скрывают окно. Клики получает только крестик.
   Swift-помощник читает геометрию физического выреза; второй мост 5174 не переносился.
   После уточнения пользователя чёрный корпус продлён до y=0. На этом Mac
   safeTop=32, полная высота окна 112: верхние 32 px чёрные, аватар и крестик
   остаются в нижней части 80 px. Крестик повторно проверен после изменения.
3. **Внешний показ отделён от PDF.** Номер, количество и время по слайдам
   независимы от PDF. Соответствие PDF подтверждается явно; вне его диапазона
   показывается сообщение, а не другая страница. Keynote/PowerPoint опрашиваются
   каждые 1,5 секунды. Для Chrome/стрелок можно задать начальный номер:
   позиция остаётся оценочной, количество неизвестно. Смена источника во время
   сеанса заблокирована; обрыв связи не подменяет внешний показ локальной колодой.
   Реальный показ и разрешения macOS ещё требуют проверки на машине выступающего.
4. **Регистрация остаётся демо.** Имя и почта необязательны и не сохраняются;
   авторизация не добавлялась.
5. **Архив сервера пока доступен через API.** Существующие методы чтения PDF
   и сессий сохранены, но новых экранов библиотеки и серверной истории нет.

## Где ещё нужен дизайн

- Панель «Где листать слайды»: выбор цели и процесса, подключение и ошибки.
  Она оставлена с исходным оформлением и изолированными CSS-правилами.
- Настройки Electron-чёлки: выбор дисплея, отключение, состояние оболочки и
  показ/скрытие функционально готовы. Оформление новых контролов требует дизайна.
- Внешний режим студии: источник номера слайда, оценочная позиция и соответствие
  загруженного PDF презентации Keynote/PowerPoint/Chrome.
- Библиотека сохранённых PDF и серверная история, если они нужны в интерфейсе.
  Это новые экраны, а не утраченные при переносе готовые страницы.
- Понятные состояния при отсутствии моста, недоступном приложении и отсутствии
  разрешений macOS. Существующие сообщения сохранены.

## Проверка

`npm run build`, `npm test` — тесты, `npm run lint`, `git diff --check` проходят.
Дополнительные проверки подтверждают связь жестов design с внешней целью
ровно по одному шагу, блокировку и передачу `handScores` без пикселей камеры.

В браузере проверены лендинг, регистрация, обучение без камеры, студия,
загрузка тестового PDF, сохранение заметок в SQLite, старт/пауза/завершение,
сохранение результата, работа колоды при отключённом мосте и ширина 390 px
без горизонтального переполнения. Electron запускается и рисует новый аватар.

Живая камера и показ в реальных Keynote/PowerPoint после переноса не проверялись.
Их адаптеры покрыты прежними тестами с подставными целями; эти тесты не заменяют
проверку на машине выступающего. Поведение на внешнем дисплее и в полноэкранном
Space после изменения размера окна отдельно не перепроверялось.

## Локальный запуск

```bash
npm ci
cp .env.example .env.local # если собственного .env.local ещё нет
npm run server
npm run dev
npm run overlay            # отдельный терминал, по необходимости
```

Студия: `http://localhost:5173/studio`. Для чисто браузерного режима оставить
`VITE_API_BASE_URL` пустым. Для внешнего показа использовались
подставные приложения и отдельная временная БД.

## Проверка функциональных доработок

В Electron проверены настоящий крестик, появление при старте, скрытие и настройка
отключения. После перезагрузки отключение сохраняется. На тестовом показе из 18
слайдов правильно отображались номера 15–17 при PDF из 3 страниц; время записано
на 16-й и 17-й слайды, пауза исключена. Проверены оценочный номер 8, неизвестное
количество и отказ команды при остановке моста без перехода к локальному PDF.
TypeScript оболочки и сервера проверен отдельно. Новый полноэкранный показ на
внешнем мониторе, живая камера и реальные Keynote/PowerPoint не проверялись.
