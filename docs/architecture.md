# Архитектура AxiomPitch MVP

## Браузерная цепочка

```text
getUserMedia (без микрофона)
  -> ImageBitmap (один кадр в обработке, не более ~14 FPS)
    -> Web Worker
      -> Hand Landmarker: 21 точка каждой кисти
      -> Pose Landmarker Lite: точки головы и тела
    -> зеркальные координаты тела и кистей
      -> Three.js: овальная голова с глазами и две 3D-ладони
      -> GestureEngine: команда / конкретная подсказка
        -> слайд, блокировка, микроанимация, статистика
```

MediaPipe/WASM работает на CPU в отдельном Worker. ES-модуль загрузчика WASM
кешируется браузером, поэтому адаптер переустанавливает ModuleFactory для
каждой инициализации задачи. Камера, Worker, таймеры и ImageBitmap освобождаются
при отключении, ошибке или размонтировании.

## 3D-аватар

Сцена загружается отдельным модулем, чтобы Three.js не увеличивал основной
пакет интерфейса. Голова — матовый синий овал с двумя маленькими тёмными глазами.
Материалы и освещение мягкие, без сильных бликов. Каждая ладонь содержит пять пальцев с тремя суставами.
Положение и изгиб пальцев сглажены по координатам Hand Landmarker.
Поворот головы приблизительно оценивается по носу и линии глаз Pose Landmarker;
это не распознавание эмоций или точное отслеживание взгляда.

Без камеры видна спокойная поза. При команде аватар даёт короткий локальный
отклик. Reduced motion отключает декоративное моргание и покачивание.
Рендер ограничен примерно 30 FPS, DPI — максимум 2. При размонтировании
освобождаются геометрии, материалы, WebGL-контекст и ResizeObserver.
Сегментация отключена: пиксельная маска для 3D-аватара не требуется.

## Собственные правила жестов

Точки зеркальны: вправо означает вправо в отображении камеры.
Ладонь считается открытой по четырём выпрямленным пальцам. Проверяются её
высота относительно плеч, видимость у границ кадра, движение относительно
ширины плеч и допустимая вертикальная составляющая. Удержание — 1,5 секунды.
Команда требует опустить руку для повторного срабатывания. Блокировка
отключает свайпы, но оставляет удержание для разблокировки.

GestureEngine — независимый класс, проверяется тестами без камеры.
Неточные попытки отделены от обычного ожидания и потери отслеживания.

## Слайды и аудитория

PDF.js локально растеризует до 60 страниц в JPEG-превью, помещённые в память.
Документ и canvas освобождаются после чтения. Лимит входного файла — 30 МБ.
Заметки хранятся в состоянии React, презентация не переживает перезагрузку.

Окно аудитории открывается на том же origin с одноразовым UUID сессии.
BroadcastChannel передаёт текущий слайд и событие завершения, без камеры.
В браузере без поддержки этой схемы можно показывать основное окно вручную.

## Сессия

SessionClock считает активное время по слайдам через performance.now().
Паузы исключены. Снимок итогов содержит время, три счётчика команд и
счётчики конкретных типов подсказок. Последние 10 результатов хранятся в
localStorage; результат можно экспортировать в JSON.

## Границы MVP

Фронт полностью работает без сервера. Серверный контракт описан отдельно,
но запросов к нему пока нет. Бек отвечает за постоянное хранение презентаций,
заметок и истории; камера и распознавание остаются на фронте.

Чёлка живёт внутри страницы. Desktop overlay и управление сторонними
приложениями не реализованы.
