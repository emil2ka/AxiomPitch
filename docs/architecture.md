# Архитектура AxiomPitch MVP

## Браузерная цепочка

```text
getUserMedia (без микрофона)
  -> ImageBitmap (один кадр в обработке, не более ~14 FPS)
    -> Web Worker
      -> Hand Landmarker: 21 точка каждой кисти
      -> Pose Landmarker Lite: точки головы и тела
    -> зеркальные координаты тела и кистей
      -> Three.js: овальная голова с глазами и две 3D-ладони
      -> GestureEngine: команда / конкретная подсказка
        -> слайд, блокировка, микроанимация, статистика
```

MediaPipe/WASM работает на CPU в отдельном Worker. ES-модуль загрузчика WASM
кешируется браузером, поэтому адаптер переустанавливает ModuleFactory для
каждой инициализации задачи. Камера, Worker, таймеры и ImageBitmap освобождаются
при отключении, ошибке или размонтировании.

## 3D-аватар

Сцена загружается отдельным модулем, чтобы Three.js не увеличивал основной
пакет интерфейса. Голова — округлая голубая фигура со светлыми глазами и короткой улыбкой.
Материал Lambert и один направленный свет создают мягкий объём. Каждая ладонь —
один SkinnedMesh с пятью цельными пальцами и тремя костями на палец.
Ориентация кисти вычисляется по мировой 3D-базе запястья и пястных суставов;
quaternion.slerp сглаживает повороты, включая вид сбоку и тыльную сторону.
Метки handedness сохраняют принадлежность рук при пересечении центра кадра.
Поворот головы приблизительно оценивается по носу, линии глаз и глубине ушей Pose Landmarker;
это не распознавание эмоций или точное отслеживание взгляда.

Без камеры видна спокойная поза. При команде аватар даёт короткий локальный
отклик. Reduced motion отключает декоративное моргание и импульс.
Рендер ограничен максимум 30 FPS, DPI — максимум 1.5. Без камеры после
сглаживания позы GPU не перерисовывает сцену до моргания или события. Сцена
содержит 6 вызовов отрисовки и 5928 треугольников (ранее 37 и 24480). При размонтировании
освобождаются геометрии, материалы, WebGL-контекст и ResizeObserver.
Сегментация отключена: пиксельная маска для 3D-аватара не требуется.

## Собственные правила жестов

Точки зеркальны: вправо означает вправо в отображении камеры.
Ладонь считается открытой по четырём выпрямленным пальцам. Проверяются её
высота относительно плеч, видимость у границ кадра, движение относительно
ширины плеч и допустимая вертикальная составляющая. Удержание — 1,5 секунды.
Команда требует опустить руку для повторного срабатывания. Блокировка
отключает свайпы, но оставляет удержание для разблокировки.

GestureEngine — независимый класс, проверяется тестами без камеры.
Неточные попытки отделены от обычного ожидания и потери отслеживания.

## Слайды и аудитория

PDF.js локально растеризует до 60 страниц в JPEG-превью, помещённые в память.
Документ и canvas освобождаются после чтения. Лимит входного файла — 30 МБ.
Заметки хранятся в состоянии React, презентация не переживает перезагрузку.

Окно аудитории открывается на том же origin с одноразовым UUID сессии.
BroadcastChannel передаёт текущий слайд и событие завершения, без камеры.
В браузере без поддержки этой схемы можно показывать основное окно вручную.

## Сессия

SessionClock считает активное время по слайдам через performance.now().
Паузы исключены. Снимок итогов содержит время, три счётчика команд и
счётчики конкретных типов подсказок. Последние 10 результатов хранятся в
localStorage; результат можно экспортировать в JSON.

## Локальный мост

```text
вкладка спикера (камера, MediaPipe, GestureEngine)
  -- WebSocket /live: frame, command, session -->  мост 127.0.0.1:8787
                                                   |- Bridge -> цель: pitchflow,
                                                   |    keynote, powerpoint,
                                                   |    chrome, frontmost
  <-- target после каждого шага -------------------|
                                                   |- frame, command, session
                                                   v
                             Electron-окно ?overlay=1: тот же Avatar
```

Жест решает только вкладка. Мост не видит кадров и не распознаёт руки:
он получает координаты позы, команду с флагом `locked` и состояние сессии.
Команда `next`/`previous` листает подключённое приложение ровно один раз,
после шага мост читает номер слайда (`readState`) и публикует `target`.
Если номера нет, вкладка сдвигается на шаг сама и помечает позицию как
оценочную. `toggle` — блокировка жестов; во внешнее приложение она не
уходит. Цель `pitchflow` — колода самой вкладки: она листается прежним
`goTo`, а мост только зеркалит её позицию.

Keynote и PowerPoint управляются через AppleScript и работают, даже когда
приложение не впереди. Google Slides и запасной адаптер `frontmost`
получают стрелку через System Events, только если впереди именно
подключённый процесс, а не консоль, терминал, Finder или окно чёлки.

Окно чёлки — Electron-панель 320×96 без рамки: прозрачная, не берёт фокус,
пропускает клики, висит на уровне screen-saver на всех Space, включая
полноэкранные. Оно грузит тот же origin Vite с `?overlay=1`, где монтируется
только Avatar. Камеры в этом окне нет, разрешения на неё отклоняются.

SQLite (`node:sqlite`) хранит презентации, заметки и итоги в `server/data/`.
Страницы PDF считает PDF.js на сервере. Итог сессии хранится как его
посчитала вкладка: сервер проверяет, что `duration` равна сумме
`perSlide`, но время по своим часам не пересчитывает.

## Границы MVP

Фронт полностью работает без сервера. При ошибке сети PDF читается
локально, итог пишется в localStorage, а колода листается в вкладке.
Мост слушает только 127.0.0.1 и работает без авторизации: это доверенный
локальный процесс на время хакатона. Управление сторонними приложениями
есть только на macOS.
